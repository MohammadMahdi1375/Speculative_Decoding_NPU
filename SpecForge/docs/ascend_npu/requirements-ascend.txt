# Reproducible Ascend NPU install for SpecForge DFlash (HF backend only).
#
# Tested target:
#   - SpecForge       @ d5fb617f735db85a680876327f8173de0cb57c15  (upstream main, 2026-05)
#   - yunchang        @ 0.6.4 (PyPI; native NPU ring/hybrid CP since PR #169)
#   - CANN            8.5+
#   - Hardware        Atlas A2 / 910b / A3
#
# Usage:
#   pip install -r requirements-ascend.txt
#
# Notes:
#   - The --index-url below forces all packages (including torch / torchvision
#     / torch_npu) to come from the Huawei Cloud PyPI mirror. The mirror is a
#     full PyPI replica AND hosts the Ascend torch_npu wheels.
#   - As of 2026-05 the latest NPU-supported torch pair is 2.9.0; SpecForge
#     upstream's 2.9.1 is NOT yet supported by torch_npu.
#   - sglang is NOT in this file. SpecForge's eagle3_target_model.py has a
#     top-level `import sglang.srt.managers.mm_utils`, so sglang must be
#     importable for any `import specforge` to work — even with HF backend
#     at runtime. Install it via Step 4 of installation.md (clone upstream
#     sgl-project/sglang, checkout tag v0.5.9, swap pyproject_npu.toml in,
#     pip install -e). Don't put sglang here because the install needs a
#     from-source build with a pyproject swap, not a wheel-pull.
#   - flash-attn is NOT included. It has no NPU build; DFlash on NPU runs
#     with --attention-backend sdpa.
#   - yunchang is included as a dormant dependency. SpecForge imports it at
#     module load time, but DFlash with default args (sp_*=1) does not
#     exercise its sequence-parallel kernels.
